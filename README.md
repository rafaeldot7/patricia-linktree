# Linktree — Dra. Patricia Camargos

Página de links (linktree) de página única, sem scroll, para a Dra. Patricia Leite Camargos (dentista e harmonização facial), baseada no perfil público [@drapatriciacamargos](https://instagram.com/drapatriciacamargos).

Página única e autocontida (`index.html`): HTML, CSS e imagem de perfil (embutida em base64) em um só arquivo, sem dependências externas. Botões com efeito "liquid glass" (vidro fosco + distorção via filtro SVG).

## Estrutura

- `index.html` — página completa, pronta para deploy

## Rodando localmente

```bash
npx serve .
```
